# 巨大UFOボス戦（machimamore-3）

基準main: `8d8a725e847974516be9fbc9a0e9e759d6e35683`。2026-10-18。

## 作戦と人数

- 初期UFO50機の出撃・復帰待ち・予備が全て尽きると、即勝利せず3秒の警報へ進む。音が無効でもWARNING表示で伝える。
- 警報後に「BOSS戦開始・巨大UFOを破壊せよ」を表示。既存母艦のモデルが街上空へ進入し、約8秒で所定位置へ到着する。
- 巨大UFOのHPは640（通常80の8倍）。通常50機の有限ロスターとは別管理。ボスは妨害UFOを射出する。
- ボス戦の開始時に妨害UFO3体が実在する。以降、戦闘が継続している各simulation更新終端に3〜6体を保証する。撃破で不足した分は同じtick内に補充し、演出や待ち時間で3体未満にしない。追加射出は3秒間隔、最大6体。ボス自身は数えない。
- 妨害UFOは既存の飛行・レーザー・街攻撃/迎撃経路を利用する。ボス自身には別種のレーザー攻撃を追加しない。
- 巨大UFO撃破で勝利。残存妨害UFOの全滅は要求しない。街全壊・味方全滅が同じtickで起きた場合は従来どおり敗北を優先する。
- ボスへの接触は自機/僚機の撃墜とボス80HP損傷。通常UFOの「接触した双方を全HP破壊」をボスへ流用しない。死亡機体を同tickで除去するため、同じ接触を後続tickで繰り返し加算しない。
- 警報・移動・補充はsimulationの60Hz時計で進み、停止中は凍結。再出撃は初期50機戦から初期化する。

## 得点

| 内訳 | 配点・上限 |
| --- | --- |
| 初期50機 | 従来どおり撃破1,000点/機、実損傷5点/HP。最大70,000点 |
| 巨大UFO | 撃破8,000点、実損傷5点/HP。最大11,200点 |
| 妨害UFO | 最初に射出した6体のIDのみ撃破1,000点/機、実損傷5点/HP。最大8,400点 |
| 7体目以降の妨害UFO | 撃破/損傷の追加点なし。戦闘実績・命中率には記録 |
| 時間 | ボス撃破までの能動時間で従来の30,000÷(1+秒/180)。勝利時のみ |
| 街・味方損失・命中率 | 従来の減点式を継続 |

過剰ダメージは実際に減ったHPまで。ボス640HPと加点対象妨害6体480HPは初期50機4,000HPの台帳から分離する。全妨害機への正当な命中は命中率へ含むが、その改善も従来の最大10,000点減点の範囲内。無限撃破で加点は増えない。数学上の上限は119,600点、実プレイは時間が正なのでこれ未満。旧版と同じ得点尺度とは扱わずルール版を更新した。ランキング・DB・得点保存・外部送信は追加していない。

結果にはボス・妨害の加点を別表示し、初期UFO残機と巨大UFO/妨害UFOの残存状態を区別する。
