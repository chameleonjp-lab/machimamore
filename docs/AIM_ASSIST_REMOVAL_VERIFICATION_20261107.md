# マチマモレ 操縦・射線・表示の検証（2026-11-07 JST）

対象計画: [zero-series PR #13](https://github.com/chameleonjp-lab/zero-series/pull/13)。開始mainは `7afbc6a8de9e4489035ca093a97ae695b2cb1161`。カイセンK1〜K3の基準検査が合格したとの取りまとめ担当の通知後に、本作の作業branch `fix/manual-camera-aim-20261107` で実装した。本人によるマージ、配備、実機受入とは別の候補である。

## 変更

両モードの操縦からUFO追尾・画面外の旋回倍率・以前の追尾量を除いた。イージーは巡航速度を維持し、移動後の最新姿勢・実画面比で円内・1200以内・生存・敵・遮蔽を確認した場合の自動発射だけを残す。ノーマルは長押しの手動発射を維持する。両銃口のMG・機関砲は発射時の機首正面へ出て、僚機の予測射撃とUFOのレーザーは従来の役割を保つ。

操縦する指を中央に戻して保持した間は機首角を保ち、解放後は滑らかに水平へ戻す。高さだけのresizeでは各指と操作量を保持し、次のclient座標を合わせる。幅・画面向きの変更、離脱、停止では入力を解除する。別指の射撃・速度レバーや個別cancelの検査は保持した。

固定計算の前後の位置・quaternion・bank・pitchを表示専用に保持し、機体・UFO・カメラ・マーカー・照準へ同じ表示状態を渡す。照準色はその表示状態の敵味方・円内・遮蔽から求め、最新の自動発射keyを借りない。射撃・衝突・得点・時計には表示状態を渡さない。機体交代の18tickカメラ移動とEasy自動射撃待機は別に維持し、停止・再開時は表示履歴も明示解除する。
